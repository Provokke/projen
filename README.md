# projen

This is a fork of [projen/projen](https://github.com/projen/projen). See upstream for the original project and its full documentation.

projen synthesizes project configuration files such as `package.json`, `tsconfig.json`, `.gitignore`, GitHub workflows, eslint and jest settings from a well-typed definition written in code. Synthesized files should not be edited by hand; change the definition and run projen again.

Install and create a project:

    npx projen new typescript

Upstream documentation: https://projen.io
